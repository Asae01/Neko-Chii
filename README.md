# Neko-Chii! 🐱

A responsive multi-page website built for a friend's online digital store. The site serves as a storefront and catalogue for digital services including in-game top-ups, premium app accounts, and creative services.

---
🌐 Live Demo: https://asae01.github.io/Neko-Chii/

## 🌐 Pages

| Page | Description |
|------|-------------|
| `index.html` | Home page with typing animation and social links |
| `about.html` | About the seller |
| `services.html` | Main services catalogue |
| `ingamePrice.html` | In-game top-up pricing (Roblox, etc.) |
| `premiumPrice.html` | Premium apps & accounts pricing |
| `skills.html` | Animated skill bars showcase |
| `education.html` | FAQ page with accordion |
| `review.html` | Customer reviews/testimonials |
| `contact.html` | Contact page with social links |
| `socmedneeds.html` | Social media services (coming soon) |
| `proofneeds.html` | Proofs & vouches (coming soon) |

---

## ✨ Features

- Responsive design — works on mobile and desktop
- Hamburger menu for mobile navigation
- Scroll-hide header (hides on scroll down, shows on scroll up)
- Typing animation on home page
- FAQ accordion (open/close on click)
- Animated skill bars
- Smooth page transition animations
- Floating cat decorations 🐾
